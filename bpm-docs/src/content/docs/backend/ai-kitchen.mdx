AI Kitchen 是後台的流程設計中心。左側是已煮好的流程（Cooked flows）與狀態，右側 **Launcher preview** 直接預覽員工在前台 Create 頁看到的樣子——拖曳排序、換圖示，即改即見。

![AI Kitchen — Cooked flows 清單與 Launcher preview](../../../assets/screens/ai-kitchen.png)

設計一條新流程走三幕：

## Prep（備料／設計）

對談生成問卷，設計流程結構與表單、簽核路由（含並簽／會簽）、通知。

## Cook（烹調／生成）

AI 把 spec 煮成 per-flow 程式，產出 spec bundle。

## Serve（上菜／驗收部署）

進 [Sandbox](/backend/sandbox/) 試吃驗收，通過後 **Register / Publish** 上線——員工的 Quick Actions 立即看得到。
