假勤與出差相關的四隻預設流程。請假的完整走查見[請假申請：走一遍](/cases-flow/leave/)。

| 流程 | Code | 關卡骨架 | 特色規則 |
|---|---|---|---|
| **請假申請** | `LEAVE` | 申請 → 主管 → HR 歸檔 | 天數自動算（去週末）；病假/公假證明必填；≥7 天加簽 VP |
| **差旅申請** | `TRQ` | 申請 → 主管 →（視条件）→ 核定 | 出差目的地、期間、預估費用；事前核准 |
| **差旅費用核銷** | `TEO` | 申請 → 主管 → 財務 | 對應已核准的差旅單；單據金額核銷、財務把關 |
| **遠距工作 WFH** | `WFH` | 申請 → 主管 | 輕量單關簽核 |

## 使用重點

- **先申請、後核銷**：差旅費用核銷（TEO）要對應一張已核准的差旅申請（TRQ）——出差前記得先送 TRQ
- **請假的條件規則會自動觸發**：病假/公假把證明文件變必填、連續 7 天以上自動多一關加簽——不用自己判斷，表單會提示
- **第一次用系統？** 從 WFH 開始最容易上手：一關簽核、一分鐘走完一輪
