Site Setting 是站台層級的全域設定，五個分頁：

![Site Setting — Branding 白牌設定](../../../assets/screens/site-setting.png)

| 分頁 | 做什麼 |
|---|---|
| **Branding** | 客戶白牌：系統名稱、Logo、Favicon。儲存後員工端 header、登入頁、瀏覽器分頁全部換裝 |
| **Flow Groups** | 流程分組 — 員工端 Quick Actions / Create 目錄的分類（差旅假勤、採購與資產⋯⋯），拖曳排序 |
| **Feature Tables** | 各流程的功能表格設定 |
| **Deploy** | 部署相關設定 |
| **Reset** | 重置站台資料（驗收重來用；正式站慎用） |

導入到品牌交付這一步，改完 Branding 員工端重新整理即生效——demo 給客戶看「這是你們的系統」最有感的一頁。
