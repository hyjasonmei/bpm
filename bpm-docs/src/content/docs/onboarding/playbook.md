flowcook 的導入是**產品化的服務**：不寫客製 code，用 AI Kitchen 把客戶的流程談出來、煮出來、驗完收、上線。

## 標準導入四步

| 步驟 | 做什麼 | 詳見 |
|---|---|---|
| **1. AI Kitchen** | 跟客戶對談，即時生成問卷，產出 spec 並煮成可運行的流程 | [用 AI Kitchen 產流程](/onboarding/ai-kitchen-flow/) |
| **2. Sandbox 驗收** | 攔信 / persona 切換 / 時間快轉 / 重置，一個驗收員跑完整 UAT | [Sandbox UAT](/onboarding/sandbox-uat/) |
| **3. 上線準備** | 組織資料匯入（OData）、角色對應、白牌品牌、通知設定 | [組織資料匯入](/onboarding/org-import/)、[上線 checklist](/onboarding/golive-checklist/) |
| **4. 交付** | 客戶自 host 或我們代管 | [交付：代管 vs 自 host](/onboarding/delivery/) |

## 心法

- **先流程後組織**：先用 demo 組織把流程談定驗完，最後才切真實組織資料——避免流程和組織兩個變數一起動
- **每一步都有可看的東西**：AI Kitchen 當場出問卷、Sandbox 當場跑單，客戶不用「想像」
- **驗收就是教學**：帶客戶驗收員跑 Sandbox 的過程，就是在教他們日後自己用
