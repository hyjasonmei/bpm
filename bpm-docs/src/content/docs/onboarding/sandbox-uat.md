Sandbox 功能本身見[後台 Sandbox 驗收](/backend/sandbox/)；這頁講**驗收怎麼跑**。導入期第一輪通常由 flowcook 顧問陪跑，之後貴公司的驗收員可以自己重複任意多輪。

## 驗收前準備

1. 後台開啟**全域 sandbox** + 要驗的流程開**攔信**
2. 確認 demo 組織資料齊全（每個會路由到的角色都有人）
3. 準備驗收腳本：每隻流程列出「正常走完」+ 至少一條「退件重送」

## 每隻流程的驗收節奏

1. 用**申請人身分**送一張單（persona 切換即可，不用登出登入）
2. 打開**攔信信箱**，確認主管收到的通知信內容正確
3. 切到**簽核者身分**核准 → 確認案件前進、下一關收到通知
4. 走一次**退件**：填退件原因 → 切回申請人看到退回 → 改單重送
5. 有逾時規則的流程用**時間快轉** +7 天，確認提醒有發

## 驗完一輪

- 驗收表對著腳本逐條簽核確認
- **全部清空**重置測試資料
- 有缺陷就回 [AI Kitchen](/onboarding/ai-kitchen-flow/) 調整設計出新版本，再驗一輪——Sandbox 可以無限重來，這就是它存在的理由
