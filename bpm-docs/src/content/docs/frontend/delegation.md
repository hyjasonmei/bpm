主管休假時流程不能停。**代理人**功能讓你在設定期間內，把「看到並代簽你的待辦」的權限交給指定同事。

![代理人設定 — 指定代理人與生效期間](../../../assets/screens/delegation.png)

## 怎麼設（委任方）

上方導覽列 **代理人** → 搜尋選人、設起迄日期 → 儲存。

- 對方會收到**委任邀請**，**接受後才生效**——狀態一路顯示：等待對方接受 → 已接受・未到生效期 → 生效中
- 反悔隨時可**取消**；期間結束自動失效

## 收到委任邀請（代理方）

- 代理人按鈕上會出現待回應數字，面板裡對每筆邀請按**接受 / 拒絕**
- 生效期間，畫面上方會有藍色橫幅提示「你目前是 X 的代理人」，你的收件匣會看到對方的待辦並可代為簽核

:::note
代理人跟 dev 模式的 persona 切換是兩回事：委任是**正式功能**（有邀請、有期限、有稽核），persona 切換只是開發/驗收用的快速登入。
:::
