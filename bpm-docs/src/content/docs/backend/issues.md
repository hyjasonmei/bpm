員工在前台 Help 選單按 **Report an issue** 送出的回報，全部集中在這一頁。不用另外開信箱或表單系統，回報進來就帶著**回報人、所在頁面、瀏覽器版本**，追問成本降到最低。

## 怎麼運作

1. 員工送出回報（bug / 功能建議 / 使用問題），系統管理員即時收到通知（站內 + email）
2. 這一頁依狀態追蹤：**未處理 → 處理中 → 已結案**（可重新開啟）
3. 點一筆展開完整描述與回報人的聯絡方式，處理完按**結案**

## 使用建議

- 導入初期建議每天看一次「未處理」——上線第一週的問題最值錢，多半是表單設計或權限設定要調
- 重複出現的「使用問題」代表該頁的操作不夠直覺，值得回饋給 flowcook 顧問調整
