金額與資產相關的五隻預設流程——這一群的共同點是**財務關**與**金額條件路由**。

| 流程 | Code | 關卡骨架 | 特色規則 |
|---|---|---|---|
| **採購申請** | `PURCHASE_REQUEST` | 申請 → 主管 → 採購 →（金額條件）財務 | 品項明細、金額門檻加簽 |
| **廠商採購請款** | `VENDOR_EXPENSE` | 申請 → 主管 → 財務 | 對供應商發票請款；供應商資料可接[資料集](/backend/datasets/) |
| **資產採購** | `FAP` | 申請 → 主管 → IT/總務 → 財務 | 固定資產入帳資訊 |
| **資產處分** | `FAD` | 申請 → 主管 → 財務 | 報廢/轉讓；殘值與處分方式 |
| **預支現金** | `APE` | 申請 → 主管 → 財務 | 預支金額與歸墊期限 |

## 演示建議

- 用 **PURCHASE_REQUEST** 演金額門檻：小額主管簽完就過，大額多過財務——同一張表單兩種路徑
- 用 **VENDOR_EXPENSE** 演下拉選單吃資料集（供應商清單）
