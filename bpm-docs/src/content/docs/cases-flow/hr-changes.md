人事異動兩隻流程的特點是**多部門接力**：一張單牽動 HR、IT、主管多方動作。

| 流程 | Code | 關卡骨架 | 特色規則 |
|---|---|---|---|
| **新進員工報到** | `EOB` | HR 發起 → 各單位準備（帳號/設備/座位）→ 主管確認 | 到職日驅動；多方待辦並行 |
| **員工離職** | `ETM` | 申請 → 主管 → IT 收回 → HR 結算 | 交接確認、帳號停用、離職日結算 |

## 演示建議

- 這兩隻適合演 **unified inbox** 的價值：IT 的 Dave 同一個收件匣看到報到要開帳號、離職要收帳號，不用進兩套系統
- 離職流程結案後，記得在 [User & Role](/backend/user-role/) soft-delete 該員工——順便演組織維護的閉環
