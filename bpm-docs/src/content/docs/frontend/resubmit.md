被退件不是世界末日——大多數流程的退件是**退回補件**（`ResubmitRequired`），不是終局否決。

## 被退回了（申請人視角）

1. 收到退回通知，案件狀態變 **退回補件 / ResubmitRequired**，簽核時序上看得到退件者的意見
2. 案件頁底部出現 **修正後重新送出 / Resubmit** → 開啟預填好原內容的表單，改完按「重新送出」
3. 案件進入**新的審核回合**，頁面會標示「第 N 次送出」——審核者看得到這張單來回過幾次

:::tip
多數流程走「退回補件 → 可重送」的迴圈；少數流程（如請假）退件即終局 `Rejected`，要重新開新單。設計流程時可指定（見[流程設計原則](/onboarding/design-principles/)）。
:::

## 撤回申請（自己收回）

送出後發現填錯、或不需要了：案件還在跑的期間，申請人可在案件頁按 **撤回申請 / Withdraw**（有確認視窗，撤回後無法復原）。案件變 `Cancelled`，要重來就開新單。

## 三種「單子結束」的差別

| 狀態 | 意思 | 誰造成的 |
|---|---|---|
| `Completed` | 走完全部關卡，正常結案 | 流程自己 |
| `Cancelled` | 申請人自己撤回 | 申請人 |
| `Rejected` | 審核者終局否決（僅部分流程） | 審核者 |
