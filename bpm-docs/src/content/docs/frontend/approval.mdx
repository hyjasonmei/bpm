簽核是主管/審核者在收件匣對案件核准或退回。並簽（多人）時，多位審核者同時待簽，達門檻或全簽才過關。

## 重點

- 單簽：一位審核者核准 → 進下一關
- 並簽（全簽 AND）：每位都要核准；一人退回 → 全退
- 並簽（M/N 門檻）：達門檻票數即通過，其餘自動略過
- 示範流程：`CONTRACT_REVIEW`（2/2 全簽）、`COMMITTEE_REVIEW`（2/3 門檻）
