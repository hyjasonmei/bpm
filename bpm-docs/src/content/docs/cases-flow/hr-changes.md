人事異動兩隻流程的特點是**多部門接力**：一張單牽動 HR、IT、主管多方動作。

| 流程 | Code | 關卡骨架 | 特色規則 |
|---|---|---|---|
| **新進員工報到** | `EOB` | HR 發起 → 各單位準備（帳號/設備/座位）→ 主管確認 | 到職日驅動；多方待辦並行 |
| **員工離職** | `ETM` | 申請 → 主管 → IT 收回 → HR 結算 | 交接確認、帳號停用、離職日結算 |

## 使用重點

- **多部門的待辦都進同一個收件匣**：IT 在自己的收件匣會同時看到「報到要開帳號」「離職要收帳號」，不用切系統或等信轉來轉去
- **離職結案後記得維護組織**：管理員在 [User & Role](/backend/user-role/) 將該員工停用（soft-delete）——保留歷史簽核紀錄，帳號不再能登入
