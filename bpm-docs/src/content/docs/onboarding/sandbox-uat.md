Sandbox 功能本身見[後台 Sandbox 驗收](/backend/sandbox/)；這頁講**怎麼帶**。

## 驗收前準備

1. 後台開啟**全域 sandbox** + 要驗的流程開**攔信**
2. 確認 demo 組織資料齊全（每個會路由到的角色都有人）
3. 準備驗收腳本：每隻流程列出「正常走完」+ 至少一條「退件重送」

## 帶著跑的節奏（每隻流程）

1. **申請人身分**送一張單（用 persona 切換，不用登出登入）
2. 開**攔信信箱**給客戶看「主管收到的信長這樣」
3. 切到**簽核者身分**核准 → 看案件前進、下一關收到通知
4. 演一次**退件**：填退件原因 → 切回申請人看到退回 → 改單重送
5. 有逾時規則的流程用**時間快轉** +7 天，看提醒有沒有發

## 驗完一輪

- 客戶簽字的驗收表對著腳本逐條勾
- **全部清空**重置測試資料
- 缺陷回 [AI Kitchen](/onboarding/ai-kitchen-flow/) 改 spec 煮新版，再驗一輪——Sandbox 可以無限重來，這就是它存在的理由
